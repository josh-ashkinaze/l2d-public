# Codebook: `exp1_prompts.json`

**Unit of observation:** One (question, source, perturbation factor) tuple — i.e., a single experimental trial presenting one claim from one source to an LLM.

Each tuple is generated by crossing a question–answer pair with a news source and a perturbation factor. The LLM first answers the question (prior), then is shown a sourced claim and re-answers (posterior). 

---

## Question / Answer

| Field | Type | Description |
|---|---|---|
| `question` | string | The question posed to the LLM (e.g., "What is the average age a horse lives?") |
| `original_answer` | float | Ground-truth answer |

---

## Dataset / Source Metadata

| Field | Type | Values | Description |
|---|---|---|---|
| `dataset` | string | `trec`, `gss`, `TriviaQA`, `NumerSense`, `world_bank` | Source dataset for this question |
| `split` | string | `test` | Train/test split; this file contains only test records |
| `question_uuid` | string (UUID) | — | Unique identifier for the question; used as join key with results files |

### Dataset descriptions

| Dataset | Description |
|---|---|
| `trec` | Numeric subset of the TREC user-query dataset; ground truth manually verified by authors |
| `TriviaQA` | Numeric subset of the TriviaQA benchmark (miscellaneous trivia) |
| `NumerSense` | Numeric world-knowledge benchmark with a scientific focus |
| `gss` | Novel questions generated from the General Social Survey (U.S. public opinion, longitudinal) |
| `world_bank` | Novel questions generated from World Bank Development Indicators (global economic/demographic data) |

---

## GSS and World Bank Fields

Populated for `dataset == "gss"` and `dataset == "world_bank"`; `null` for all other datasets.

| Field | Type | Description |
|---|---|---|
| `year` | float | The year the question pertains to (survey year for GSS; data year for World Bank) |
| `series` | string | The variable or indicator the question is about (GSS variable name, e.g., `"agekdbrn"`; World Bank indicator name, e.g., `"Arable land (hectares per person)"`) |
| `custom_metadata` | object | Additional metadata. GSS: `{"question_type": "count", "year_type": "post_internet"}`. World Bank: `{"year_type": "post_internet", "oecd": 0}` |

---

## GSS-Specific Fields

Only populated for `dataset == "gss"`; `null` for all other datasets.

| Field | Type | Description |
|---|---|---|
| `series_answer` | string | Key identifying the specific GSS answer (e.g., `"agekdbrn_average_2014"`) |

---

## World Bank-Specific Fields

Only populated for `dataset == "world_bank"`; `null` for all other datasets.

| Field | Type | Values | Description |
|---|---|---|---|
| `oecd` | string / null | `"oecd"`, `"non-oecd"` | Whether the question refers to an OECD member country |

---

## Stratification Variables

Used to ensure balanced sampling across substantive sub-populations.

| Field | Type | Values | Datasets | Description |
|---|---|---|---|---|
| `post_internet` | string / null | `"post_internet"`, `"pre_internet"`, `null` | `gss`, `world_bank` | Whether the question pertains to a time period before or after widespread internet adoption; `null` for other datasets |
| `strata` | string / null | `"post_internet_oecd"`, `"post_internet_non-oecd"`, `"pre_internet_oecd"`, `"pre_internet_non-oecd"`, `null` | `world_bank` | Cross of `post_internet` × `oecd`; `null` for other datasets |

---

## Source

Each question is paired with one news web domain from a pool of 132 sources, stratified by reliability and popularity.

| Field | Type | Description |
|---|---|---|
| `source` | string | Web domain of the news source (e.g., `"eastdfwnews.com"`) |
| `source_reliability` | float | Source reliability score (Lin et al. 2023 PC1 composite); higher = more reliable |
| `source_reliability_bucket` | int {1, 2} | `1` = low reliability; `2` = high reliability |
| `source_popularity` | float | Source popularity score; higher = more widely read |
| `source_popularity_bucket` | int {1, 2, 3} | `1` = low, `2` = medium, `3` = high popularity tier |

---

## Claim (Perturbation)

The claim is the value the source is said to assert, generated by multiplying the ground truth by a perturbation factor.

| Field | Type | Description |
|---|---|---|
| `perturbation_factor` | float {0.33, 0.5, 1.0, 2.0, 3.0} | Multiplier applied to `original_answer` to produce the claim: `claim_value = original_answer × perturbation_factor` |
| `claim_value` | float | The value asserted by the source: `original_answer × perturbation_factor` |
| `claim_distance` | float | Absolute distance between the claim and the truth: `\|claim_value − original_answer\|` |
| `correct` | int {0, 1} | `1` if the claim equals the ground truth (i.e., `perturbation_factor == 1.0`); `0` otherwise |

### Perturbation factor semantics

| Factor | Meaning |
|---|---|
| `0.33` | Claim is ⅓ of truth — large understatement |
| `0.5` | Claim is ½ of truth — moderate understatement |
| `1.0` | Claim equals truth — no misinformation |
| `2.0` | Claim is 2× truth — moderate overstatement |
| `3.0` | Claim is 3× truth — large overstatement |

---

## Identifiers

| Field | Type | Description |
|---|---|---|
| `claim_id` | string | Unique identifier for this specific (question, source, perturbation factor) tuple. Format: `{question_uuid}_{source}_{perturbation_factor}` |
